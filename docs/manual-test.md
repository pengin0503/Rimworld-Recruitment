# ゲーム内テスト手順

クラウド環境ではビルド・単体テスト・XML の静的チェックまでを行っています。ゲーム内の動作は、この手順で確認してください。

## 準備

1. このリポジトリのフォルダーを `RimWorld/Mods/` に置きます。`About/` と `1.7/` がフォルダー直下にある状態にします。
2. MOD 一覧で Harmony と「入植者募集」（Colonist Recruitment）を有効にします。Harmony を上にします（MOD 一覧の並び替えで自動的にそうなります）。
3. 設定 → 開発者モードを有効にします。
4. 新しいコロニーを始めます。DLC の確認をする場合は、各 DLC を有効にしておきます。
5. 確認中は、ログ（開発者モードの「ログを開く」）に `[Recruitment]` や例外が出ていないかを、随時見てください。

便利な開発者操作:

- シルバーを出す: 開発者パレットの Spawn thing → Silver。
- 研究を終わらせる: Debug actions → Research → Finish all research（または該当する研究だけ終わらせる）。
- 時間を進める: 速度を上げるか、メインタブ「募集」の `DEV: arrive now` ボタンを使います。開発者モードの時だけ表示され、確定済みの応募者数も表示されます。

## 1. 基本表示

- [ ] 画面下部に「募集」タブがあり、開くと「進行中の募集」「判断待ちの応募者」「募集方式」「派閥と拠点」「募集履歴」が表示される。
- [ ] 募集方式の一覧に4方式がアイコン付きで出ていて、それぞれ「今のマップで使えるか」が緑（使えます）か赤（理由）で表示される。研究が終わっていない無線放送・軌道通信には「研究が必要」と出る。シルバーを減らすと、0.5秒ほどで理由が「シルバーが足りません」に変わる。
- [ ] 「派閥と拠点」に、人型の派閥ごとに友好値と関係、直接依頼ができるか（できなければ理由）が出る。敵対派閥は「敵対している派閥です」。
- [ ] MOD 設定画面が開き、値を変えると一覧の費用・日数に反映される。「初期設定に戻す」で元に戻る。
- [ ] MOD 設定の「応募者の人数」に「社交0のとき」「社交20のとき」の2組のスライダーと、「社交10のとき」の確率が出る。初期値では社交10が 15% / 20% / 38% / 28%（表示の丸め）になる。
- [ ] MOD 設定に「シルバーの上乗せ: 候補の評価」の4つのスライダー（情熱の小・大、できない仕事、健康上の問題）がある。「高額な募集の開始前に確認する」と使者の社交補正の設定は、もう無い。

## 1.5 募集開始画面（すべての方式で共通）

以下の各方式で、開始の前に必ずこの画面が出ることを確認してください。

- [ ] 方式のアイコンと名前、応募者の出身（固定ならその派閥、抽選なら「入植者を送ってくれる派閥から抽選」）、到着先、到着方法、期間が出る。
- [ ] 「担当: （入植者名）（社交 N）」と、0〜3人の確率が出る。社交の高い入植者で開くと、0人の確率が下がり、2〜3人が上がる（初期設定の社交20で 5% / 15% / 50% / 30%）。
- [ ] 上乗せの4段階（なし／少し／多め／最大）が選べ、それぞれ追加の割合・シルバー・候補数が出る。選ぶと費用の合計と「支払い後」の額が変わる。
- [ ] 足りない段階を選ぶと、「支払い後」が赤い「不足」になり、赤字の理由が出て、「開始」が押せなくなる。
- [ ] 「キャンセル」と右上の×で、何もせずに閉じる。
- [ ] 一度「最大」で開始したあと、次に開くと「最大」が選ばれている（ゲームを再起動すると「なし」に戻る）。

## 2. キャラバンで募集

- [ ] Debug actions → Execute incident → `TraderCaravanArrival` で商人キャラバンを呼ぶ。
- [ ] 入植者を選択して商人を右クリックすると、「キャラバンで募集（50シルバー、6〜10日）」が出る。
- [ ] シルバーが50未満だと、項目は無効になり、理由（必要量・所持量）が表示される。
- [ ] 選ぶと募集開始画面が出る。担当は右クリックした入植者、出身は商人の派閥、支払いは「商人と話し終えた時点」と表示される。
- [ ] 「開始」を押すと入植者が商人のところへ行き、少し話したあとで「開始しました」のメッセージが出る。シルバーが、選んだ段階の合計（なし50、少し75、多め100、最大150）だけ減る。
- [ ] 上乗せ「多め」を選んで開始し、商人に話しに行く途中でシルバーを減らして75にすると、話し終えた時点で「シルバーが足りません（必要 100…）」が出て、開始されない。
- [ ] 同じマップで、もう一度実行しようとすると「すでに1件の募集が進行中」で無効になる。
- [ ] 入植者が商人に話しかけている途中で商人が立ち去る（Debug actions で商人を消すなど）と、「商人が立ち去ったか交易をやめたため…頼めませんでした」のメッセージが出る。
- [ ] 帝国のキャラバン（Royalty）は、ナイト未満だと交易と同じ理由で無効になる。ナイトになると有効になる。

## 3. 無線放送・軌道通信

- [ ] 通信機を建て、電力を通す。入植者を選択して通信機を右クリックすると、バニラの派閥一覧と同じメニューに「入植者募集を呼びかける」が出る。研究が1つも終わっていなければ「研究が必要」で無効になっている。
- [ ] 選ぶと入植者が通信機を使い、派閥との交渉と同じ形式の画面が開く。「無線放送」と「軌道通信」が費用・期間付きで並び、研究していない方式・シルバー不足・同時募集の上限などは理由付きで無効になっている。
- [ ] 停電中や電力なしのときは、バニラの理由（電力なしなど）で通信機自体が使えない。
- [ ] 無線放送（250）か軌道通信（600）を選ぶと、交渉画面が閉じて募集開始画面が出る。担当は通信機を使った入植者、出身は「抽選」。「開始」で募集が始まり、シルバーが合計額だけ減る。
- [ ] 「回線を閉じる」で何もせずに閉じられる。
- [ ] 軌道通信の応募者は、輸送ポッドで降下して到着する。
- [ ] （Odyssey）宇宙マップでは、無線放送は「宇宙では使えません」で無効になり、軌道通信は使える。
- [ ] 他の派閥への通信（交渉画面）がこれまでどおり使える。

## 3.5 派閥への直接募集（派閥との通信画面）

準備: 通信機と電力、研究（無線放送か軌道通信）、シルバー。開発者モードの交渉画面にある「(Debug) Goodwill +10 / -10」で友好値を調整できます。

- [ ] 通信機で友好的な派閥（友好値10以上）との通信を開くと、最初のページの「（切断）」の上に「入植者の募集を依頼する（友好値10とシルバー）」が出る。友好値がその派閥の自然な値より高いと、10ではなく11〜13と表示されることがある（バニラのトレーダー要求と同じ補正）。
- [ ] 選ぶと「…どの方法で入植者を募ってもらいますか？」のページになり、無線放送・軌道通信が費用付きで並ぶ。研究していない方式は理由付きで無効。「戻る」で最初のページに戻る。
- [ ] 方式を選ぶと交渉画面が閉じ、募集開始画面が出る。出身はその派閥（固定）、費用に「友好値: -10（現在 → 依頼後）」が出る。
- [ ] 「開始」で募集が始まり、「…が無線放送で入植者を募ってくれることになりました…友好値 -10」のメッセージが出る。友好値が表示どおり下がり、シルバーが合計額だけ減る。
- [ ] 募集タブの進行中の募集に「（直接依頼）」が付き、「派閥と拠点」のその派閥が「直接依頼の結果待ち」になる。同じ派閥の通信を開くと、項目が「前回の依頼の結果がまだ出ていません」で無効。別の派閥には依頼できる。
- [ ] 応募者が到着したあと（または0人で失敗したあと）は、同じ派閥に再び依頼できる。
- [ ] 友好値が9以下の派閥では「友好値が0を下回ります（必要 10、現在 N）」で無効。友好値10ちょうどなら依頼でき、依頼後は0になる。
- [ ] 敵対している派閥では「敵対している派閥です」で無効。
- [ ] （Royalty）帝国は、ナイト以上の入植者がいないと「交易に必要な爵位を持つ入植者がいる入植地にしか…」で無効。
- [ ] 社交ができない入植者で通信すると、バニラの依頼と同じく「社交を行わない」で無効。
- [ ] 届いた応募者の出身が、依頼した派閥になっている。
- [ ] 宇宙マップ（Odyssey）では、無線放送が「宇宙では使えません」で無効、軌道通信は使える。

## 4. 使者（キャラバンで拠点に依頼）

準備: 敵対していない派閥の拠点が近くにあるワールドで、入植者2人以上とシルバーを用意します。

- [ ] シルバーを持たせずにキャラバンを編成し、ルートの行き先にその拠点を選んで出発しようとすると、「…シルバーを0しか持っていません…このまま出発しますか？」の確認が出る。了承するとバニラの警告（食料など）に続いて出発でき、キャンセルすると編成画面に戻る。
- [ ] 行き先が依頼できない拠点（敵対、または待ち時間中）や、行き先なしのときは、この確認は出ない。
- [ ] シルバーを100以上持たせて出発したキャラバンを選択し、ワールドマップで拠点を右クリックすると、「使者による募集（100シルバー、4〜7日）」が出る。シルバーが足りないキャラバンでは、理由付きで無効になる。
- [ ] 選ぶと（拠点が複数あれば到着先を選んだあと）募集開始画面が出る。担当はキャラバンの交渉役、使えるシルバーはキャラバンの所持量、支払いは「…に到着した時点で、キャラバンの持ち物から」と表示される。
- [ ] 「開始」でキャラバンが拠点へ向かい、到着すると「…に入植者の募集を依頼しました」のメッセージが出て、キャラバンのシルバーが合計額だけ減る。募集タブに、その派閥出身の募集が、選んだ上乗せの段階付きで表示される。
- [ ] 上乗せ「最大」（300）で出発させ、移動中にキャラバンのシルバーを200に減らすと、画面右側に警告「使者のキャラバンのシルバー不足」が出る。説明に「必要 300、所持 200」が出る。到着しても依頼は成立せず、理由のメッセージが出る（シルバーは減らない）。
- [ ] 拠点を訪問中のキャラバンを選択すると、「入植者の募集を依頼」ボタンが出る。押すと募集開始画面が出て、「開始」でその場で依頼できる。
- [ ] 同じ拠点にもう一度依頼しようとすると、「最近依頼したばかりです（あと…）」で無効になる。設定の待ち日数を0にすると、すぐ依頼できる。
- [ ] 敵対している拠点には、依頼の項目もボタンも出ない。
- [ ] 帝国の拠点（Royalty）は、キャラバンにナイト以上の入植者がいないと、理由付きで無効になる。
- [ ] キャラバン中の入植者は入植者バーに表示され、近親者が亡くなると思考が付く（バニラのキャラバンと同じ）。
- [ ] 期間が過ぎると、応募者が入植地のマップの端から歩いて来る（キャラバンの帰還とは関係なく来る）。

## 5. 到着と判断（加入方式: 受け入れ選択）

- [ ] 到着すると「応募者N人が到着」のレターが届く。レターを開くと応募者画面が出る。
- [ ] 画面に、各応募者の肖像、年齢、出身、思想、特性、技能、健康状態が表示される。情報カードのボタンで詳細が見られる。
- [ ] 一部を「不採用」にして確定すると、採用した人だけがマップの端から歩いて来て入植者になる。
- [ ] 「あとで決める」で閉じても、レターや募集タブの「確認する」から開き直せる。
- [ ] 募集タブの「確認する」を何度押しても、同じ応募者画面は1つしか開かない。
- [ ] 判断時間（設定で1時間にすると確認しやすい）を過ぎると、応募者は去ったというメッセージが出て、レターが消える。
- [ ] 期限を過ぎた瞬間に、募集タブの「判断待ちの応募者」からも消える（残り0のまま残らない）。
- [ ] 応募者の派閥・ゼノタイプ・思想が、出身派閥のものになっている。MOD 種族の派閥がある場合は、その種族の応募者も来る。

## 5.5 上乗せと候補の評価

- [ ] 上乗せ「最大」で募集し、`DEV: arrive now` で到着させる。応募者の技能が、上乗せなしで募集したときより全体に高い傾向がある（何回か比べる）。応募者画面の内容（技能・できない仕事・健康）は、ふつうの応募者と同じ形で出る。
- [ ] 到着時にログにエラーや警告（`[Recruitment]` や「Tried to …」）が出ない。選ばれなかった候補は、拒否した応募者と同じ方法で破棄されるので、入植者の家族関係に見知らぬ人が増えない。
- [ ] MOD 設定で「できない仕事1つごと」を30にして「最大」で募集すると、できない仕事のある応募者が来にくくなる。
- [ ] 上乗せで0人になった場合も、シルバー（上乗せ分を含む）は返らない。

## 6. 自動加入

- [ ] 設定で加入方式を「自動加入」にする。到着すると、応募者がそのまま入植者として歩いて来て、加入のレターが届く。

## 7. セーブとロード

次の各状態でセーブしてロードし、状態が保たれていることを確認してください。

- [ ] 募集の進行中（残り日数・上乗せの段階・「（直接依頼）」の表示が変わっていない）。
- [ ] 拠点へ依頼に向かうキャラバンの移動中（到着すると、選んだ上乗せの額で依頼が成立する）。
- [ ] 上乗せ付きで商人に話しに行く途中（ロード後に話し終えると、選んだ段階の額が引かれる）。
- [ ] 直接依頼の結果待ち（ロード後も、同じ派閥には依頼できない）。
- [ ] 1.0 のセーブ（進行中の募集あり）をロードすると、上乗せ「なし」として表示され、予定どおり到着する。1.0 の MOD 設定で変えていた人数の重みは「社交0のとき」に入っている。
- [ ] 依頼した拠点の待ち時間中（ロード後も同じ拠点には依頼できない）。
- [ ] 入植者が通信機へ向かっている途中（ロード後に交渉画面が開く）。
- [ ] 旧バージョン（1.0）で使者が不在中・出発途中のセーブをロードすると、使者は拠点に戻され、出発途中だった場合は費用が返る。不在中だった募集の応募者は予定どおり来る。
- [ ] 応募者の判断待ち（レターと応募者画面が開ける）。

## 8. 拠点の移動（Odyssey）

- [ ] 募集中にグラヴシップで移動する。移動先の拠点に応募者が到着し、募集タブに「拠点が失われたため別の拠点へ」と表示される。
- [ ] 飛行中に到着時刻が来ても失敗にならず、着陸後に到着する。
- [ ] 別に地上の拠点がある状態でグラヴシップが飛行中のときは、その地上拠点への到着は保留されずに行われる。

## 既知の制限

- 応募者が判断待ちの状態で MOD を外すと、その応募者はセーブから失われます（使者は普通のキャラバンなので影響を受けません）。


## 9. レビュー修正版（#17–#21）

- [ ] 2拠点A/Bを用意し、Aの入植者を多くする。Aで1件募集済み、Bは0件の状態で使者の依頼ができ、Bへ届く。
- [ ] 両拠点に空きがあるとき、使者の出発指示と訪問中のボタンの両方で到着先を選択できる。指定した拠点を移動中のセーブ・ロードでも保持する。
- [ ] 選択した拠点を破棄、または募集枠を埋めてから使者を到着させると、課金されずに理由が表示される。
- [ ] 到着時の代替拠点選択は、既存募集の枠を理由に応募者を拒否しない。
- [ ] 病気・義肢・特性・できない仕事が多い3人を応募者画面で表示する。全文をスクロールでき、行が重ならない。英語/日本語、UI倍率変更でも確認する。
- [ ] テスト用パッチでSetFaction、Notify_BackFromAway、到着ワーカーの各段階を1回だけ例外にする。採用済み/未処理の全員がマップ・輸送コンテナ・保持コンテナ/WorldPawnsのいずれかに残る。
- [ ] 3人中2人目で失敗させ、回復待ちの状態でセーブ・ロードする。処理済みの人が重複せず、保存した採否で残りを再試行する。選択加入/自動加入の両方を確認する。
- [ ] 到着ワーカーがポッドへ移送/Spawnした直後に例外を出しても、既に移送済みの人を回収・再生成しない。
- [ ] 採用確定後にグラヴシップが飛行中になった場合、応募者を期限切れで破棄せず、着陸後に移送を再試行する。
- [ ] 通常完了、0人抽選、生成失敗、到着先消失、期限切れ、回復待ちが履歴で区別される。開始/最終結果の時刻、支払額、人数、到着先を確認する。
- [ ] 回復待ちから完了しても履歴が二重にならない。101件以上で古い履歴から消え、ロード後も100件以内。
- [ ] レターを削除しても履歴は残り、募集中の確定済み人数は開発者モード以外に漏れない。
- [ ] 履歴のない旧セーブ、採否前の旧応募者グループをロードできる。
- [ ] Releaseワークフローで単体テストを意図的に失敗させると、パッケージ化/公開に進まない（テスト用ブランチで確認し、正式タグは使わない）。
