# ゲーム内テスト手順

クラウド環境ではビルド・単体テスト・XML の静的チェックまでを行っています。ゲーム内の動作は、この手順で確認してください。

## 準備

1. このリポジトリのフォルダーを `RimWorld/Mods/` に置きます。`About/` と `1.7/` がフォルダー直下にある状態にします。
2. MOD 一覧で「入植者募集」（Colonist Recruitment）を有効にします。Harmony は不要です。
3. 設定 → 開発者モードを有効にします。
4. 新しいコロニーを始めます。DLC の確認をする場合は、各 DLC を有効にしておきます。
5. 確認中は、ログ（開発者モードの「ログを開く」）に `[Recruitment]` や例外が出ていないかを、随時見てください。

便利な開発者操作:

- シルバーを出す: 開発者パレットの Spawn thing → Silver。
- 研究を終わらせる: Debug actions → Research → Finish all research（または該当する研究だけ終わらせる）。
- 時間を進める: 速度を上げるか、メインタブ「募集」の `DEV: arrive now` ボタンを使います。開発者モードの時だけ表示され、確定済みの応募者数も表示されます。

## 1. 基本表示

- [ ] 画面下部に「募集」タブがあり、開くと「進行中の募集」「判断待ちの応募者」「募集方式」が表示される。
- [ ] 募集方式の一覧に4方式が出ている。研究が終わっていない無線放送・軌道通信には「研究が必要」と表示される。
- [ ] MOD 設定画面が開き、値を変えると一覧の費用・日数に反映される。「初期設定に戻す」で元に戻る。

## 2. キャラバンで募集

- [ ] Debug actions → Execute incident → `TraderCaravanArrival` で商人キャラバンを呼ぶ。
- [ ] 入植者を選択して商人を右クリックすると、「キャラバンで募集（50シルバー、6〜10日）」が出る。
- [ ] シルバーが50未満だと、項目は無効になり、理由（必要量・所持量）が表示される。
- [ ] 実行すると入植者が商人のところへ行き、少し話したあとで「開始しました」のメッセージが出る。シルバーが50減る。
- [ ] 同じマップで、もう一度実行しようとすると「すでに1件の募集が進行中」で無効になる。
- [ ] 入植者が商人に話しかけている途中で商人が立ち去る（Debug actions で商人を消すなど）と、「商人が立ち去ったか交易をやめたため…頼めませんでした」のメッセージが出る。
- [ ] 帝国のキャラバン（Royalty）は、ナイト未満だと交易と同じ理由で無効になる。ナイトになると有効になる。

## 3. 無線放送・軌道通信

- [ ] 通信機を建て、電力を通す。研究が終わる前に右クリックすると、「研究が必要」で無効になっている。
- [ ] 研究を終えると有効になり、実行すると入植者が通信機を操作したあとで募集が始まる。
- [ ] 停電中（電力を切る）には無効になる。
- [ ] 通信機を操作している途中で電力を切ると、「通信機が使えなくなったため…」のメッセージが出て、シルバーは減らない。
- [ ] 無線放送（250）と軌道通信（600）を選ぶと、開始前に費用・期間・到着方法の確認画面が出る。キャンセルすると何も起きない。キャラバン（50）と使者（100）では、初期設定のままなら確認は出ない。
- [ ] 設定で確認の額を0にすると、すべての方式で確認が出る。確認をオフにすると、どの方式でも出ない。
- [ ] 軌道通信の応募者は、輸送ポッドで降下して到着する。
- [ ] （Odyssey）宇宙マップでは、無線放送は「宇宙では使えません」になり、軌道通信は使える。

## 4. 使者

- [ ] 募集タブ →「使者を派遣する…」で入植者の一覧が出る。社交レベルごとに、期間の倍率と0人の確率が表示される。
- [ ] 子供・ダウン中・最後の1人などは「派遣する」が無効になり、ツールチップに理由が出る。
- [ ] 派遣すると、その入植者がマップの端へ歩いて行き、端に着くとマップから消える。「旅立ちました」のメッセージが出る。
- [ ] 歩いている途中で別の命令を出すと、派遣が取り消され、シルバーがその場に返却される。
- [ ] Shift を押しながら「派遣する」を押す（命令が後回しになる）か、中断できない作業中に派遣しても、取り消されずに、その作業のあとで出発する。
- [ ] 使者がマップを出ると、画面右側の警告欄に「不在の使者: 1人」が出る（赤い重大警告ではない）。カーソルを当てると名前と帰還までの日数、クリックで募集タブが開く。帰還すると警告が消える。
- [ ] 帰還した使者の年齢（生物学的年齢）が、不在だった日数分だけ進んでいる。
- [ ] 使者の不在中に、その使者が使っていた服装ポリシー（または薬物・食事・読書のポリシー）を削除する。帰還後、そのポリシーが既定のものに戻っていて、エラーが出ない。
- [ ] 使者の選択画面を開いたままにしても、入植者が多いコロニーでフレームレートが目立って落ちない。
- [ ] 同時募集数を2以上にし、入植者2人だけの状態で1人目を派遣すると、2人目は「ほかに自由な入植者が1人以上必要」で派遣できない。
- [ ] 期間が過ぎると、使者がマップの端から歩いて戻る（応募者0人なら1人で戻り、失敗のレターが届く）。

## 5. 到着と判断（加入方式: 受け入れ選択）

- [ ] 到着すると「応募者N人が到着」のレターが届く。レターを開くと応募者画面が出る。
- [ ] 画面に、各応募者の肖像、年齢、出身、思想、特性、技能、健康状態が表示される。情報カードのボタンで詳細が見られる。
- [ ] 一部を「不採用」にして確定すると、採用した人だけがマップの端から歩いて来て入植者になる。
- [ ] 「あとで決める」で閉じても、レターや募集タブの「確認する」から開き直せる。
- [ ] 募集タブの「確認する」を何度押しても、同じ応募者画面は1つしか開かない。
- [ ] 判断時間（設定で1時間にすると確認しやすい）を過ぎると、応募者は去ったというメッセージが出て、レターが消える。
- [ ] 期限を過ぎた瞬間に、募集タブの「判断待ちの応募者」からも消える（残り0のまま残らない）。
- [ ] 応募者の派閥・ゼノタイプ・思想が、出身派閥のものになっている。MOD 種族の派閥がある場合は、その種族の応募者も来る。

## 6. 自動加入

- [ ] 設定で加入方式を「自動加入」にする。到着すると、応募者がそのまま入植者として歩いて来て、加入のレターが届く。

## 7. セーブとロード

次の各状態でセーブしてロードし、状態が保たれていることを確認してください。

- [ ] 募集の進行中（残り日数が変わっていない）。
- [ ] 使者が歩いて出発している途中。
- [ ] 使者が不在の間（ロード後に戻ってくる。関係や装備が保たれている）。
- [ ] 応募者の判断待ち（レターと応募者画面が開ける）。

## 8. 拠点の移動（Odyssey）

- [ ] 募集中にグラヴシップで移動する。移動先の拠点に応募者が到着し、募集タブに「拠点が失われたため別の拠点へ」と表示される。
- [ ] 飛行中に到着時刻が来ても失敗にならず、着陸後に到着する。
- [ ] 別に地上の拠点がある状態でグラヴシップが飛行中のときは、その地上拠点への到着は保留されずに行われる。
- [ ] 使者がマップの端へ歩いている間にグラヴシップで出発して使者を置いていくと、派遣が取り消され、返却のシルバーは残っている拠点に置かれる（消えたマップには置かれない）。

## 既知の制限

- 不在中の使者は年をとり（誕生日・加齢による持病もバニラどおり）、記録も進みますが、空腹・休息などの欲求は変わりません。
- 不在中の使者には、近親者の死亡などの思考が付きません（ゲーム本体の全ポーン処理の対象外のため）。ポリシーと思想は、帰還時に整えます。
- 使者が不在、または応募者が判断待ちの状態で MOD を外すと、その人たちはセーブから失われます。
