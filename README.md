# Colonist Recruitment / 入植者募集

**日本語** | [English](README.en.md)

RimWorld 1.7で、費用と日数をかけて新しい入植者を募集するMODです。Harmonyが必要です。

## 募集方法

| 方式 | 費用 | 期間 | 必要研究・開始方法 |
|---|---:|---|---|
| キャラバン | 50銀 | 6〜10日 | 研究不要。入植者を選択し、来訪中の商人を右クリック |
| 使者 | 100銀 | 依頼後4〜7日 | 研究不要。銀を持つキャラバンで非敵対拠点を右クリック |
| 無線放送 | 250銀 | 3〜5日 | マイクロエレクトロニクス基礎。通信機から選択 |
| 軌道通信 | 600銀 | 1〜3日 | AIコンピュータコア。通信機から選択。到着は輸送ポッド |

値は初期設定です。応募者は0〜3人で、0人でも費用は戻りません。ワールドの派閥から来て、種族・ゼノタイプ・思想はその派閥に従います。帝国出身者にはナイト以上の入植者が必要です。

どの方式も、開始前に募集開始画面で費用・期間・人数の確率を確認できます。

- **社交補正**: 募集を始めた入植者（商人と話す人、キャラバンの交渉役、通信機を使う人）の社交が高いほど、応募者が増えやすくなります。初期設定では、社交0で0〜3人が各25%、社交20で 5% / 15% / 50% / 30%。
- **シルバーの上乗せ**: 費用に +50% / +100% / +200% を足すと、応募者1人ごとに2 / 3 / 4人の候補から、技能・情熱・できない仕事・健康で評価して最も良い人が来ます（特性は評価しません）。人数は変わりません。
- **派閥への直接募集**: 通信機で派閥との通信を開き、「入植者の募集を依頼する」を選ぶと、無線放送か軌道通信のシルバーと友好値10（バニラのトレーダー要求と同じ補正により、11〜13になることがあります）で、その派閥に直接募集を頼めます。敵対していないこと、依頼後も友好値が0以上であること、同じ派閥への前回の依頼の結果が出ていることが条件です。

初期設定では到着後24時間以内に応募者を比較し採否を決めます。自動加入も選べます。同じ拠点への再依頼には初期設定で15日必要です。費用・期間・人数の確率・上乗せの評価・同時募集数などはMOD設定で変更できます。募集タブには、進行中の募集の進み具合、今のマップで使える方式、派閥ごとの直接依頼の可否、募集履歴（最新100件）が表示されます。

## 導入と注意

[Releases](https://github.com/pengin0503/Rimworld-Recruitment/releases) から利用可能な配布パッケージを取得し、MODフォルダをRimWorldの `Mods` に置きます。Harmonyの後に有効化して再起動してください。判断待ちの応募者がいる状態でMODを外すと、その応募者は失われます。変更前にセーブをバックアップしてください。
