# Colonist Recruitment（入植者募集）

RimWorld 1.7 用の MOD です。失った入植者を、費用と日数をかけた「募集」で補充できます。Harmony は使いません。

## 募集方式

| 方式 | 費用 | 期間 | 必要研究 | 開始方法 | 到着 |
|---|---|---|---|---|---|
| キャラバンで募集 | 50 | 6〜10日 | なし | 入植者を選択して、来訪中の商人を右クリック | 徒歩 |
| 使者による募集 | 100 | 4〜7日（社交で変化） | なし | 「募集」タブ →「使者を派遣する」 | 使者と一緒に徒歩 |
| 無線放送 | 250 | 3〜5日 | マイクロエレクトロニクス 基礎 | 入植者を選択して、電力の通った通信機を右クリック | 徒歩 |
| 軌道通信 | 600 | 1〜3日 | AIコンピュータコア | 同上（宇宙でも可） | 輸送ポッド |

- 応募者は0〜3人です（初期値は各25%）。0人のときは費用が戻りません。
- 応募者はワールドの派閥から来ます。種族・ゼノタイプ・思想はその派閥に従います。帝国の出身者は、入植者の誰かがナイト以上（帝国のキャラバンと交易できる爵位）のときだけ来ます。
- 初期設定では、到着した応募者を画面で比べて採用・不採用を選びます（24時間以内）。MOD 設定で自動加入にもできます。
- 費用・期間・人数の確率・使者の社交補正・同時募集数などは、MOD 設定で変更できます。

## 構成

```
About/                 MOD 情報
1.7/Assemblies/        ビルド済み DLL
Defs/                  募集方式・ジョブ・レター・メインタブの定義
Languages/             英語・日本語
Source/Recruitment/    C# ソース（Logic/ は RimWorld に依存しない計算部分）
Tests/                 Logic の単体テスト（xUnit）
tools/check_mod.py     XML・翻訳キー・Def 参照の静的チェック
docs/                  設計仕様とゲーム内テスト手順
```

## ビルド

.NET 10 SDK が必要です。参照アセンブリは NuGet の `Krafs.Rimworld.Ref`（1.7.4985）を使うので、ゲーム本体がなくてもビルドできます。

```sh
dotnet test Tests/Recruitment.Tests        # 単体テスト
dotnet build Source/Recruitment -c Release  # 1.7/Assemblies/Recruitment.dll を出力
python3 tools/check_mod.py                  # 静的チェック（--rimworld-data <ゲームのData> でバニラ参照も確認）
```

ゲーム内での確認手順は `docs/manual-test.md` にあります。

## 注意

- 不在中の使者と判断待ちの応募者は、この MOD のデータとしてセーブされます。その状態で MOD を外すと、その人たちは失われます。
