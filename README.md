# Colonist Recruitment / 入植者募集

**日本語** | [English](README.en.md)

RimWorld 1.7で、費用と日数をかけて新しい入植者を募集するMODです。Harmonyが必要です。

## 募集方法

| 方式 | 費用 | 期間 | 必要研究・開始方法 |
|---|---:|---|---|
| キャラバン | 50銀 | 6〜10日 | 研究不要。入植者を選択し、来訪中の商人を右クリック |
| 使者 | 100銀 | 依頼後4〜7日 | 研究不要。銀を持つキャラバンで非敵対拠点を右クリック |
| 無線放送 | 250銀 | 3〜5日 | マイクロエレクトロニクス基礎。通信機から選択 |
| 軌道通信 | 600銀 | 1〜3日 | AIコンピュータコア。通信機から選択。到着は輸送ポッド |

値は初期設定です。応募者は0〜3人で、0人でも費用は戻りません。ワールドの派閥から来て、種族・ゼノタイプ・思想はその派閥に従います。帝国出身者にはナイト以上の入植者が必要です。

初期設定では到着後24時間以内に応募者を比較し採否を決めます。自動加入も選べます。使者の社交技能が高いほど応募者0人になりにくく、同じ拠点への再依頼には初期設定で15日必要です。費用・期間・人数の確率・同時募集数などはMOD設定で変更できます。募集履歴は最新100件まで表示されます。

## 導入と注意

[Releases](https://github.com/pengin0503/Rimworld-Recruitment/releases) から利用可能な配布パッケージを取得し、MODフォルダをRimWorldの `Mods` に置きます。Harmonyの後に有効化して再起動してください。判断待ちの応募者がいる状態でMODを外すと、その応募者は失われます。変更前にセーブをバックアップしてください。
